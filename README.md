# Script Foundry

Script Foundry is a collection of practical automation, systems, security, and software projects. Each project demonstrates technical skills through clear documentation, tested code, and reproducible examples.

## Projects

### BastionAudit

A Bash-based Linux security assessment and basic hardening tool. It inventories system/security state, audits processes and permissions, enables a default-deny UFW policy, calculates a security score, and writes a timestamped owner-only report.

Project files: [`bastion-audit/`](./bastion-audit/)

This collection will grow as new tools are built, tested, and refined.
